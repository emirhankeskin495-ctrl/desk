# Project design skills

These skills are discovered automatically by OpenCode from `.agents/skills/<skill-name>/SKILL.md`.

- **frontend-design** — plan and implement distinctive product interfaces, with specific guidance for analytical dashboards and data-heavy screens. Adapted from Anthropic's published skill.
- **web-design-guidelines** — audit existing pages for accessibility, responsive behavior, interaction states, performance, and consistency. Based on Vercel's published skill workflow.

Recommended sequence for substantial UI work:
1. Load `frontend-design` before planning or implementing a new interface.
2. Load `web-design-guidelines` after implementation to audit the result.
3. Inspect a rendered desktop and mobile preview before declaring the work complete.

Skills provide instructions; they do not automatically redesign the product or guarantee visual quality.
